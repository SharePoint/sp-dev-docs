> [!IMPORTANT]
> The SharePoint Framework Online workbench is deprecated starting on May 13, 2026 and will be retired on December 1, 2026.
>
> For web parts, debug on actual SharePoint pages using the [SharePoint Framework Debug Toolbar (developer toolbar)](../../docs/spfx/debug-toolbar.md). See [Debug SharePoint Framework solutions on modern SharePoint pages](../../docs/spfx/debug-modern-pages.md).
>
> This deprecation does not apply to the **Copilot Workbench**, which is fully supported for developing and testing Copilot UX components.
