> [!IMPORTANT]
> **SharePoint Add-ins reached end of life in SharePoint Online on April 2, 2026.** Both SharePoint-hosted and provider-hosted Add-ins are retired and no longer work in SharePoint Online, including government clouds. Add-in development, deployment, and usage guidance is retained for historical reference and for applicable SharePoint Server scenarios, not for new SharePoint Online solutions.
>
> **SharePoint Server Add-ins deployed through an on-premises app catalog are not retired by this change.** Acquiring SharePoint Add-ins from the public marketplace ended on April 2, 2026 for SharePoint Server.
>
> This retirement does not retire SharePoint REST APIs, CSOM, JSOM, or [SharePoint Framework (SPFx)](../../docs/spfx/sharepoint-framework-overview.md). For SharePoint Online, use SPFx for user interface extensions and Microsoft Entra ID for authentication to external applications. See the [retirement announcement](../../docs/sp-add-ins/retirement-announcement-for-add-ins.md) and [Add-in migration guidance](../../docs/sp-add-ins-modernize/sp-add-in-modernize.md).
