> [!NOTE]
> The SharePoint Framework (SPFx) used a gulp-based toolchain from SPFx v1.0 - v1.21.1. [SPFx v1.22 transitioned to a new Heft-based toolchain, replacing the gulp-based toolchain](/sharepoint/dev/spfx/release-1.22.0).
>
> This article was originally authored for a Gulp-based SPFx version. Its implementation hasn't been fully validated with the current Heft-based toolchain. Keep its version-specific dependencies when reproducing the historical example.
>
> To move the scenario to a newer SPFx release, validate configuration, dependencies, APIs, and host behavior as well as build commands. Don't assume replacing Gulp command names is sufficient.
>
> Refer to [Understanding the Heft-based toolchain (how it works)](/sharepoint/dev/spfx/toolchain/customize-heft-toolchain-overview) for the current command model.
